Table 编辑器设计总结
Lanting Stream · Tables 树 + 双模态编辑器 · 基于 antd 5 Token 体系 · 2026
一、设计规则
从 Editor 页面 10 条设计原则推导，规范从规则推导
R1
Tables 树复用 FileTree 组件，仅参数差异化
原则 09（一处改动，全局一致）：DDL 文件和 SQL 文件是同类资源，树组件统一。差异仅限 rootPath='tables/'、fileExtension='.ddl'、图标 ti-database。不新建组件，不新建 model。所有样式通过 antd CSS 变量驱动，自动跟随亮/暗色主题。
R2
双模态共享同一底板，切换不产生色差跳动
原则 07（底板内部背景完全一致）：表单和文本编辑器在同一块 colorBgContainer 白色底板内，模式切换只替换内容区。Segmented 控件放在内容区顶部，和 FileTabs 之间有 0.5px colorSplit 极细分隔。
R3
表单降低门槛，文本提供精细控制
原则 02（以交互为原则）：表单模式服务于不熟悉 DDL 语法的用户，快速建表。文本模式服务于需要精细控制的用户。默认打开表单模式，降低入门门槛。两种模式各有用处，都有资格留下。
R4
模式切换用 Segmented 控件，放在编辑器内容区顶部
原则 R1（视觉权重匹配功能层级）：模式切换属于编辑器内部行为。Segmented 是 antd 原生控件，承载两个选项安静不抢眼。默认态无背景色，激活态切换为白色卡片，hover 文字变深。
R5
保存逻辑按模态区分：表单显式确定，文本自动保存
原则 01（让界面消失）+ 02（以交互为原则）：表单模式需要用户点「确定」后序列化为 CREATE TABLE DDL 写盘；文本模式直接取 CodeMirror 内容，使用现有 1.5s 自动保存 + saveGeneration 竞态控制机制。
R6
焦点稳定：状态变化只改背景色
原则 05（焦点稳定）：表格行 hover/选中用 colorBgTextHover / controlItemBgActive，文字颜色和字重不变。输入框 focus 边框变 colorPrimary，加 2px 浅蓝光晕。删除按钮 hover 变 colorError，不常驻红色避免误操作恐惧。

模式切换 · 数据同步规则
表单 → 文本 将表单数据序列化为 Flink DDL：CREATE TABLE ... (字段列表) WITH (属性) 完整语句，写入 CodeMirror。
文本 → 表单 解析 Flink DDL 提取表名、字段列表、连接器类型、WITH 键值对，回填表单。不支持的特性保留在内部状态，切回文本时恢复。
冲突处理 表单 → 文本：直接覆盖。文本 → 表单：如有表单不支持的特性，顶部展示 warning 提示 "文本中的自定义内容在表单模式下保留但不可编辑，切回文本时恢复"，不丢数据。
切换时机 点击 Segmented 按钮立即执行同步并切换。不弹确认框——因随时可以切回去，不打断用户心流。

九、实现路径
分步落地，每步可独立验证
P1
Tables 树：FileTree 接受 rootPath + fileExtension 参数
FileTree 组件新增 rootPath prop（默认 ''）和 fileExtension prop（默认 '.sql'）。Tables 视图传入 rootPath='tables/'、fileExtension='.ddl'。图标根据 fileExtension 自动切换。FileTreeHeader title 也参数化。
P2
后端：FileIndexService 扩展 DDL 解析
识别 .ddl 后缀文件，解析 Flink CREATE TABLE 语句提取表名、连接器类型（WITH 'connector'）、字段列表。索引只存表名/连接器/字段，不存 WITH 属性；属性校验直接读盘解析。
P3
DdlEditor 容器：Segmented 切换 + 双模态管理
新建 DdlEditor 组件，作为 EditorPanel 中 DDL 文件的内容渲染器。根据 fileExtension 判断——.ddl 文件渲染 DdlEditor，.sql 文件渲染 CodeEditor。状态管理扩展 editor model。
P4
DdlFormEditor：四段式表单编辑器
四段：基本信息（表名 input + 连接器 select）、字段定义（可编辑表格，三列 + 删除）、分区字段、连接器属性（键值对表格）。所有样式通过 theme.useToken() 获取 antd token，CSS 中用 var(--ant-*)。
P5
双向同步：parseDdlToFormData / serializeFormToDdl
实现 Flink DDL 解析器（解析 CREATE TABLE、字段列表、WITH 属性）和序列化器。文本 → 表单时检测不支持的特性，展示 warning 提示。切换逻辑在 DdlEditor 容器层实现，点击 Segmented 立即切换。
